## Shell Script
A shell script is a text file containing a list of commands that instruct an **OS** to perform specific task

The Shell is an interface that interpretates, processes and executes these commands from the script

---
## Basic CLI Commands 

The CLI is a powerful tool for interacting with our computer using text commands 

It is referred to as shell, terminal, console, or promt.

- cd - To Nav between directory 
- ls - It lists files and directory in the current location
- pwd - print working directory
- mkdir - make directory
- rmdir - remove empty directory
- cp - copy 
- mv - move
- rm - remove
- touch - create empty files
- clear - clear terminal
- cls - clear screen 
- ps - display process in terminal 
- cat - concatenate multiple files 
- chmod - change file protection mode
- grep - search a file for some pattern
- cal - view calendar in terminal 
- wc - checks the lines, word count and character and file using different options
