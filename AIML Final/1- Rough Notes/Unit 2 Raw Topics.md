### 2. Types of Machine Learning

* **Understanding These With Graphs, Examples, and Mathematical Expressions Using Real World Studies If Possible Give Links To Relevant Graphs**: This section will be supported by visual aids to illustrate the concepts clearly.
* **2.1. Supervised (Inductive) Learning**: The model learns from a **labeled dataset** where each data point is paired with its correct output. The goal is to map input features to output labels.
    * **2.1.1. Regression**: Predicts a **continuous numerical value**. The output is a number, not a category.
        * *Example*: Predicting the temperature tomorrow based on historical data.
    * **2.1.2. Classification**: Predicts a **categorical label**. The output is a class or category.
        * *Example*: Classifying an image as containing a "cat" or "dog."
* **2.2. Unsupervised Learning**: The model finds hidden patterns and structures in **unlabeled data** without any prior guidance.
    * **2.2.1. Clustering**: Groups similar data points together based on their inherent characteristics.
        * *Example*: Grouping customers into different market segments for targeted marketing.
    * **2.2.2. Dimensionality Reduction**: Reduces the number of features (variables) in a dataset while preserving its most important information. This simplifies the data for modeling and visualization.
* **Understanding Agent Environment Interface**:
    * **2.3. Reinforcement Learning**: An agent learns through trial and error by interacting with an environment. It receives **rewards** for taking beneficial actions and **penalties** for poor ones, learning a policy that maximizes its cumulative reward over time.
    * **Inverse Reinforcement Learning**: Infers the reward function that an expert agent is trying to optimize, based on its observed behavior.
* **2.4. Semi-supervised Learning**: A hybrid approach that uses a **small amount of labeled data** and a **large amount of unlabeled data** for training. It's particularly useful when obtaining labeled data is expensive or time-consuming.

### 3. Feature Engineering

* **3.1. Understanding Features**
    * **What is a feature?**: In machine learning, a feature is an individual measurable property or characteristic of a phenomenon being observed. **Feature engineering** is the art of transforming raw data into useful features that a model can effectively learn from.
    * **Importance and why it is used?**: The quality of features directly impacts model performance. Well-engineered features can significantly improve a model's accuracy, reduce its training time, and provide better insights.
    * **Main Process Of Feature Engineering**:
        * **Data Prep**: Cleaning and structuring raw data.
        * **Exploratory Analysis**: Analyzing the data to understand relationships and distributions.
        * **Benchmark**: Establishing a baseline model performance to measure the impact of feature engineering.
    * **3.1.1. Feature vs. Variable**: A **variable** is a raw data column, while a **feature** is a variable that has been prepared and is ready for model consumption.
    * **Feature and their types**:
        * **Numerical Features**: Represent quantities.
            * *Continuous*: Can take any value in a range (e.g., height, temperature).
            * *Discrete*: Can take a finite number of values (e.g., number of children).
        * **Categorical Features**: Represent categories or groups.
            * *Nominal*: Categories without an inherent order (e.g., 'red', 'blue', 'green').
            * *Ordinal*: Categories with a defined order (e.g., 'small', 'medium', 'large').
        * **Datetime Features**: Data related to time and dates.
        * **Text Features**: Unstructured text data.
* **3.2. Preprocessing Data**
    * **3.2.1. Handling Missing Data**: Essential for preventing model errors and biases.
        * **Techniques**:
            * **Imputation**: Filling missing values with a statistical measure (mean, median, mode) or a predicted value.
            * **Flagging**: Creating a new binary feature to indicate that a value was missing.
            * **Label Encoding, One-Hot Encoding, Target Encoding, Frequency Encoding**: These are not for missing data but are methods for encoding categorical features, often done in conjunction with handling missing data in that category.
            * **Deletion**: Removing rows or columns with missing values (only suitable when a small amount of data is missing).
            * **Prediction models**: Using one model to predict and fill in missing values for another.
    * **3.2.2. Dealing with Categorical Features**: Machine learning models cannot directly process text labels, so they must be converted to numerical format.
        * **Encoding Methods**:
            * **One-Hot Encoding**: Creates new binary columns for each category.
            * **Label Encoding**: Assigns a unique integer to each category.
            * **Target Encoding**: Replaces each category with a statistical measure of the target variable (e.g., the mean) for that category.
* **3.3. Working with Features**
    * **Why Should We Use Features Scaling?**: Scaling is crucial for many algorithms to prevent features with larger magnitudes from dominating the learning process.
        * **Gradient Descent Based Algorithms**: Scaling speeds up convergence.
        * **Distance Based Algorithms**: Scaling ensures all features contribute equally to distance calculations.
        * **Tree Based Algorithms**: These are generally not sensitive to scaling.
    * **3.3.1. Feature Scaling**:
        * **Methods**:
            * **Normalization**: Scales features to a range, typically [0, 1].
            * **Standardization**: Scales features to have a mean of 0 and a standard deviation of 1.
    * **3.3.2. Feature Selection**: The process of selecting a subset of the most relevant features to improve model performance and reduce training time.
        * **Filter Methods**: Uses statistical tests to score and select features independently of the model.
        * **Wrapper Methods**: Uses a specific machine learning model to evaluate the performance of a subset of features.
        * **Embedded Methods**: The feature selection is performed as part of the model's training process.
        * **Feature Selection Algorithms**:
            * **Instance Based Approaches**: Uses specific data instances to guide selection.
            * **Nondeterministic Approaches**: Uses random search methods to find optimal feature subsets.
            * **Exhaustive Complete Approaches**: Evaluates all possible feature combinations.
    * **3.3.3. Feature Extraction**: The process of creating new, more informative features from the original ones.
        * **Principal Component Analysis (PCA)**: A widely-used algorithm for dimensionality reduction. PCA transforms a set of possibly correlated variables into a new set of uncorrelated **principal components**, which are linear combinations of the original features. The first few components capture most of the variance in the data, allowing for significant dimensionality reduction.
